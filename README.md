# ☕ CIL Space — Landing Page Concept

A clean, modern, and fully responsive landing page designed for **CIL Space (Coffee Improvement Learning)** based in Bogor, Indonesia.

Built to showcase the cafe's unique concept—combining a cozy learning space with specialty coffee—while replacing generic bio link tools with a brand-tailored digital experience.

---

## ✨ Features

- 📱 **Fully Responsive Layout:** Optimized for mobile, tablet, and desktop viewports.
- 📖 **Brand Storytelling:** Highlights CIL Space's tagline (*"Grow with peers & coffee"*).
- ☕ **Interactive Sections:**
  - About / Concept overview
  - Menu & Promo highlights
  - Operating hours & Location info
  - Direct links to WhatsApp Order/Reservation & Google Maps
- ⚡ **Fast & Lightweight:** Pure HTML5, CSS3/Tailwind, and JavaScript for instant load times.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3 / Tailwind CSS** — Custom styling & responsive layouts
- **JavaScript (Vanilla)** — Interactivity
- **Vercel / Netlify** — Deployment
